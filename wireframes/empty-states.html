۱) توضیح صفحه (خاکستری کم‌رنگ): یک جمله «این صفحه برای چیست» — فقط در حالت خالی، لیست که پر شد توضیح هم می‌رود.
۲) پیام خالی بودن: همان متن‌های فعلی.
۳) دکمه افزودن: همان فرمی که speed dial صفحه باز می‌کند.
پیاده‌سازی — کامپوننت موجود EmptyState یک prop اختیاری description می‌گیرد (توضیح صفحه). صفحاتی که الان EmptyState دارند فقط description می‌گیرند؛ صفحاتی که div دستی دارند به EmptyState مهاجرت می‌کنند.
صفحات نیازمند اصلاح (از بررسی کد):
• OpeningBalancePage — div دستی
• VehicleDetailTabContent — div دستی، آیکون generic
• TimesheetDetailPage — markup تکراری دستی
• DangSplitExpensesTab / PeopleTab / SummaryTab — دستی
• RecordsPage حالت فیلتر — باید SearchEmptyState شود
• WalletAccountDetailPage — EmptyState بدون دکمه
• DashboardPage حالت not-configured — div دستی
بقیه (چک‌ها، طلب‌ها، بدهی، اقساط، صندوقچه، …) EmptyState + دکمه دارند، فقط description اضافه می‌شود.
دمو: تب‌ها = نمونه متن ۴ صفحه.
